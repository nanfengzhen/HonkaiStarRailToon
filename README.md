| **脸部 SDF** | 根据光照与头部方向控制面部明暗，包含控制图左右翻转、肤色和阴影颜色过渡。 |

| **刘海阴影** | 单独生成相机视角下的头发深度图，画脸时比较遮挡，再与 SDF 受光结果结合。 |

| **头发着色** | LightMap 控制的 Toon／Ramp 明暗，以及 **N·H 阈值高光**。 |

| **眼透与眉透** | 用 Stencil 标记眼眉区域，让覆盖这些区域的刘海局部透明；透明程度随观察方向和贴图 Alpha 变化。 |

| **身体与服装** | LightMap 材质分区、Ramp 明暗、**8×8 浮点 LUT 驱动的分区高光**，以及单／双面剔除、背面 UV 和法线处理。 |

| **丝袜** | 在不透明身体上实现局部遮罩、平铺细节和 **N·V 视角变色**，表现薄纱质感。 |

| **几何描边** | 网格外扩、宽度控制、距离补偿，并支持透视和正交相机。 |

| **深度边缘光** | 根据当前像素与偏移采样位置的深度差，生成头发和身体的局部边缘光。 |

| **角色自阴影** | 从太阳光方向生成角色专用阴影图，进行柔化采样，参与身体明暗和高光控制；投影随太阳光同步。 |

| **场景投射与接收阴影** | 角色能向地面投影，也能接收 Cube 等场景物体的阴影。这是你后来要求补充的 Unity 场景适配。 |

| **身体局部视角染色** | 根据 N·V 和 LUT，让指定材质分区随视角压暗、相对偏蓝。 |

| **服装局部流光** | 帽子紫色星纹和胸前细长饰件中的动态亮点，由流图、双向噪声和遮罩共同控制。 |
